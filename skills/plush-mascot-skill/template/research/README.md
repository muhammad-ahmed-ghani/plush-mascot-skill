# Reference research (optional)

If a real object or another product inspired the design, record what you studied and keep three kinds of statement apart: **observed** (what the reference visibly shows), **inferred** (what you conclude from it), **confirmed** (verified against a source such as the maker's documentation). State what was taken (for example "short plush, felt appliqu\u00e9 face") and what was deliberately not (shape, face, palette). The originality check in the skill's image-generation playbook uses this note.
