# Font licences

The page's fonts are self-hosted subsets, all under the SIL Open Font License 1.1 (https://openfontlicense.org):

- Fraunces (headlines), https://github.com/undercasetype/Fraunces
- Alegreya Sans (text), https://github.com/huertatipografica/Alegreya-Sans
- Covered By Your Grace (margin notes), https://fonts.google.com/specimen/Covered+By+Your+Grace

Subsets are rebuilt by `scripts/dev/build-fonts.py`. Keep this file with the fonts.
