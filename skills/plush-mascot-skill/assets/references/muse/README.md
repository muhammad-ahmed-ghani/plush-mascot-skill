# Muse reference material (inspiration only)

Screenshots and two short status clips collected while studying how a plush agent companion is presented in a product. Use them to see how the character earns its place in an agent UI, not to copy a design (the originality guard in `references/image-generation.md` still applies: describe your own character in your own terms and never attach these as references to an image model).

| File | What it shows |
|---|---|
| `landing-working.jpg`, `hatch-working.mp4` (3.8 s), `hatch-connecting.mp4` (4.0 s) | the product landing page's working state and its two status clips: a plush character with headphones typing at a laptop; small hand, head and body motions rather than large gestures |
| `shopping-detail.jpg`, `booking-detail.jpg`, `travel-detail.jpg` | agent task flows (shopping and approval, browser booking, travel) with the character present beside the work |
| `timeline-01.jpg`, `timeline-02.jpg`, `timeline-03.jpg` | frames from the product demo video's timeline |
| `instagram.png` | a social post presenting the character |

What the material showed, as observed: the avatar is the visible participant of a persistent conversation; the text beneath it states what is being worked on; selecting it reveals activity and earlier approvals; the working state is calm and legible (headphones, laptop, restrained typing); decisions the person must make are handed over with an open palm and a card, not decided by the mascot. These informed the template's ten states and the approval demo (`references/rig-and-animation.md`).

Not established by any public source inspected: the character's modelling package, groom, renderer, rig or asset pipeline. Any claim about those tools would be speculation, and nothing in this skill depends on it. The skill's own pipeline (generated art, fitted sculpt, fabric shader, measured face) is documented in `references/`.
