# Examples (the template's example mascot)

- `states-contact-sheet.jpg`: the ten application states of the live model (idle, greeting, listening, thinking, working, approval, success, error, speaking, resting), stepped from the real controller. This is the bar: thin curled fibres, a rolled hood-to-face edge, satin eyes, no gloss.
- `art-qa-example.json`: `art_qa.py` reports for the example registered front, hero, turnaround and use-case sheet (all pass); the format your own reports will have.
- `validation-example.md`: the example's full validation report with real numbers (use `template/tests/VALIDATION.template.md` for yours).
- `prompt-pack-example/`, `prompt-pack-owl/`: the prompt packs `render_prompts.py` makes from `prompts/brief.example.json` and `prompts/brief.owl.example.json` for both model families.
